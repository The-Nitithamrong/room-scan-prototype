# Room Scan — ต้นแบบ UX

ต้นแบบ Web App สำหรับมือถือ (iPhone / Android ไม่ต้องมี LiDAR): ถ่ายภาพห้องแบบมีผู้ช่วยนำทาง
วัดระยะอ้างอิง 1–2 จุด แล้วแก้แปลน 2D ดูโมเดล 3D และส่งออกไฟล์

**เปิดใช้งาน:** https://the-nitithamrong.github.io/room-scan-prototype/

> ⚠️ **ต้นแบบเท่านั้น** — ยังไม่มีระบบประมวลผลภาพบนเซิร์ฟเวอร์ และยังไม่ได้ทดสอบความแม่นยำกับห้องจริง
> ระยะจากภาพถ่ายเป็นค่าประมาณ งาน built-in งานกระจก และงานก่อสร้างต้องวัดหน้างานด้วยเครื่องมือจริงเสมอ

## ความเป็นส่วนตัว

- ไม่มี backend — **ภาพและแปลนเก็บในเบราว์เซอร์ของเครื่องที่ใช้เท่านั้น** ไม่มีการอัปโหลด
- ลบภาพของห้องได้ทันทีในแอป (หน้าสรุป หรือปุ่ม "ลบ" ที่หน้าแรก)
- ก่อนถ่าย ควรเก็บเอกสาร รูปบุคคล หน้าจอที่มีข้อมูลส่วนตัว และหลีกเลี่ยงการถ่ายติดคนในบ้าน
- ไลบรารีที่โหลดจากภายนอก: Three.js 0.160.0 (MIT) จาก cdn.jsdelivr.net เฉพาะตอนเปิดมุมมอง 3D

## ความปลอดภัยระหว่างถ่าย

ระหว่างเดินถ่ายให้มองทางเป็นระยะ ระวังสายไฟ ขอบพรม เฟอร์นิเจอร์ และบันได
อย่าเดินถอยหลังขณะมองจอ และอย่าปีนเก้าอี้เพื่อถ่ายเพดาน

## หน้าจอ

| หน้า | ทำอะไรได้ |
|---|---|
| `index.html` | รายการห้อง, ตรวจความพร้อมของอุปกรณ์, เปิดแปลนตัวอย่าง |
| `capture.html` | ถ่ายภาพแบบมีผู้ช่วย (ตรวจความคม แสง ลายพื้นผิว การซ้อนทับ การสั่น มุมก้ม/เงย นับก้าว) → ตรวจภาพ → วัดระยะอ้างอิง → สรุป |
| `editor.html` | แก้แปลน 2D (ลากมุม/ผนัง ประตู หน้าต่าง ตั้งสเกล undo), ดู 3D, ส่งออก JSON / SVG / DXF / GLB |

iPhone: กด "อนุญาต" ทั้งกล้องและเซนเซอร์การเคลื่อนไหวเพื่อให้มีคำแนะนำมุมกล้อง
ควรเปิดใน Safari หรือ Chrome โดยตรง (การเปิดจากในแอป LINE/Facebook อาจใช้กล้องไม่ได้)

## พัฒนาต่อ

vanilla HTML/CSS/JS ไม่มี build step · ทดสอบ: `npm test` (Node 18+)
กล้องบนมือถือต้องเปิดผ่าน HTTPS เสมอ ถ้ารันเองให้ใช้เซิร์ฟเวอร์ที่มี HTTPS

repo นี้เป็นสำเนาสำหรับเผยแพร่ของโฟลเดอร์ `room-scan/prototype` ใน repo หลัก (ส่วนตัว)
ซึ่งมีเอกสาร feasibility, architecture, แผนทดสอบ และ PoC
